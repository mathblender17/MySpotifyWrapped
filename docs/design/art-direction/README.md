## Approved approach

There is **one system with a different world at each station**: F (wayfinding) is the frame, C sets the rule for hero numbers, and each station gets its own style. Style changes happen during rides or as morphs (one style transforming into the next). Full detail is in the spec: [../../superpowers/specs/2026-10-25-art-direction-design.md](../../superpowers/specs/2026-10-25-art-direction-design.md).

# Ongaku Densha Art Plan 1 (System + 4 Proof Stations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the approved art-direction system in place (shared tokens, grain, restyled anchors, station sign and arrival ritual, sound accents, act-2 night sky) and restyle four contrasting stations: **1 Departure (F)**, **5 Sumo (D)**, **8 Gacha (K)**, **10 Fuji (I)**. Together they prove the mix holds together before the other nine are built.

**Architecture:**
- **Styles are data.** Each station declares its `world` and `accent` in `STATIONS`. The player hands the accent to the station sign and the ticket. Slides get the shared grain from the `slide()` helper.
- **World styling is plain CSS,** one file per world under `src/slides/worlds/`, scoped by the slide's class.
- **One new transition device:** a pixel wipe for the gacha arrival.
- **Sound accents** are synthesised with Web Audio behind the soundtrack's unlock and mute.

**Tech Stack:** As now: Vite, TypeScript, GSAP, Three.js, Vitest/jsdom, plus headless Chrome for the visual checks. No new dependencies.

**Spec:** [docs/superpowers/specs/2026-10-25-art-direction-design.md](../specs/2026-10-25-art-direction-design.md). Mockups: [docs/design/art-direction/](../../design/art-direction/README.md).

**Branch:** `art-direction` (spec is already committed there).

## Global Constraints

- Every Phase 1/2 constraint still holds: real numbers only; every stat a slide shows today is still shown; files stay on device; no Spotify branding; reduced motion; taps; sound unlock and mute.
- Palette core: paper `#f4efe6`, ink `#111111`, signal red `#e60012`, gyaru pink `#ff2d95`. Pink appears on every station.
- Each station's hero stat is in **Dela Gothic One**, tabular figures, at least 30% of the slide width (≥ 63 design px at the 210 px design width).
- One accent face per world beyond the core (Dela Gothic One, Zen Kaku Gothic New):

  | World | Accent face |
  |---|---|
  | F | Archivo Black |
  | D | Reggae One |
  | K | Press Start 2P + DotGothic16 |
  | I | Shippori Mincho + Yuji Syuku |

- Grain: `.grain` uses `multiply` at 0.35 on light grounds and `screen` at 0.18 on dark grounds (`.grain.dark`).
- Sound accents sit at −18 dB (gain 0.125) under the music. They play only when unlocked and not muted, and never with reduced motion.
- Station sign beat: 0.45 s, `power3.out`. Reduced motion: instant.

## Review Focus

1. **A station whose world isn't restyled yet (Plan 2 ones)** still works and gets the sign and grain, with no broken styling (test in Task 2).
2. **The pixel wipe when the source stub is missing** (konbini passed through? It never is, but the cut fallback rule applies). Expected: it falls back to a ride (test in Task 6).
3. **Sound accents before unlock, while muted, or with reduced motion.** Expected: silence and no AudioContext created (test in Task 8).
4. **Long names in the new layouts** (a 40-character artist or song name in the manga splash, the JRPG window or the F sign). Expected: wraps or ellipsis, never overflow outside the slide (test in Tasks 4–7).
5. **The manga image fails to load** (offline). Expected: the panels still show screentone, so it's not an empty frame (test in Task 5).

**Files:** `src/slides/gacha.ts`, `src/slides/worlds/k.css`, `src/journey/transitions.ts`, `src/journey/stations.ts`; tests in `tests/slides/worlds.test.ts` and `tests/journey/transitions.test.ts`

- CRT scanlines over everything (`.k-scan`).
- The flash beat stays: a white screen flash before the SSR window.
- The slide is created with `{ dark: true }`.

**Pixel wipe (spec §6, morph `pixelate`):**
- `Station.morph?: 'pixelate'`; gacha has `morph: 'pixelate'`.
- In `runTransition`, a `baton` with `o.morph === 'pixelate'` and a `cut.from` element present builds a 12×21 grid of blocks over the stage in K's palette (`#2b1a6b`, `#5b2a8a`, `#b4447e`, `#ff8a5b`, `#ffd36b`):
  - blocks appear in a fixed shuffled order (seeded, deterministic) over 0.5 s, covering the outgoing slide;
  - the outgoing slide is removed and the incoming one set visible;
  - blocks disappear in reverse order over 0.5 s.
- Total 1.0 s. All blocks are removed at the end.
- Without `cut.from`, it falls back to ride (Review Focus 2). Reduced motion: 0.2 s crossfade.

> **Why a wipe, not a true mosaic:** CSS can't mosaic arbitrary DOM, and SVG filters on HTML are unreliable on iOS Safari. A block wipe in K's palette reads as "pixelating into the game" and works everywhere.

    - after `progress(1)` only `inEl` remains;
    - a missing `.kon .bc` gives the same duration as ride;

### Task 8: Sound accents

**Files:**
- Create: `src/audio/sfx.ts`
- Modify: `src/audio/soundtrack.ts` (expose `unlocked`), `src/story/player.ts`
- Test: `tests/audio/sfx.test.ts`

**Interfaces:**
- `createSfx(opts: { canPlay: () => boolean; makeContext?: () => AudioContext }): { chime(): void; don(): void; blip(): void; bell(): void; dispose(): void }`
  - The `AudioContext` is created lazily on the first allowed play, never before.
  - Each call builds oscillator(s) → gain (peak 0.125, short envelope) → destination:

    | Sound | Recipe |
    |---|---|
    | chime | sine 880 Hz 0.25 s, then 660 Hz 0.35 s |
    | don | sine 70 Hz with a pitch drop to 40 Hz over 0.25 s, plus a short noise burst |
    | blip | square 1320 Hz, 0.06 s |
    | bell | sine 220 Hz with partials 2.76× and 5.4×, 2.5 s decay |

- `Soundtrack` gains `readonly unlocked: boolean`.
- The player creates `sfx` with `canPlay = () => !!soundtrack?.unlocked && !soundtrack.muted && !reduced`, and wires:
  - `chime()` at each sign show;
  - `don()` at the sumo Yokozuna beat (a timeline `call` at that beat's position);
  - `blip()` at each K window beat;
  - `bell()` at kanji arrival.

- [ ] **Step 1: Write the tests** (fake AudioContext recording created nodes)
  - With `canPlay` false, `chime()` creates no context (Review Focus 3).
  - With `canPlay` true, `chime()` creates one context and two oscillators, and the gain peak is ≤ 0.125.
  - A second `chime()` reuses the context.
  - `dispose()` closes it.
  - Player: arriving at a station with a stub sfx calls `chime` once; muted → `canPlay` is false.
- [ ] **Step 2:** Run it. Expected: FAIL.
- [ ] **Step 3:** Implement.
- [ ] **Step 4:** Run `npx vitest run`. Expected: PASS.

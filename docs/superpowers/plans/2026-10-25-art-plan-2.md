# Ongaku Densha Art Plan 2 (The Other Nine Stations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the nine stations Art Plan 1 left (torii, bento, ganguro, idol, konbini, weather, shinkansen, omikuji, kanji) into their worlds, build the four remaining morphs and the arrival flourishes, and ship the found pictures with their credits. When this plan is done, the whole ride matches the approved art direction.

**Architecture:**
- **Same system as Plan 1:**
  - one CSS file per world in `src/slides/worlds/`;
  - stats and beats stay as they are;
  - hero numbers are set in Dela Gothic One;
  - the station sign and grain come for free.
- **Morphs** are added to the `morph` union on `Station`. `runTransition` runs a morph when its source shape is on screen and otherwise falls back to the ride, exactly like `pixelate`.
  - **Flight morphs** move a clone with `x`/`y`/`scale`.
  - **Overlay morphs** flood the stage with colour or ink.
- **Arrival flourishes** on ride arrivals are new beat effects inside the arriving slide (`grow`, `steps`, `brush`, `drain`). They follow reduced motion for free.
- **Images:** one optimised WebP of the Kabukicho photo, used by three worlds, always with a visible credit.
- **Fonts:** each world's accent fonts load only when its station is near.

**Tech Stack:** As now: Vite, TypeScript, GSAP, Three.js, Vitest/jsdom, plus headless Chrome over the DevTools protocol for visual and layout checks. No new dependencies.

**Spec:** [docs/superpowers/specs/2026-10-25-art-direction-design.md](../specs/2026-10-25-art-direction-design.md) (§5 stations, §6 morphs, §9 images, §13 font risk). Mockups: [docs/design/art-direction/picks.html](../../design/art-direction/picks.html). Plan 1: [2026-10-25-art-plan-1.md](2026-10-25-art-plan-1.md).

**Branch:** `art-plan-2`, from `main` at `08c745f`.

## Global Constraints

- **Unchanged from Phases 1, 2 and Plan 1:**
  - real numbers only, and every stat a slide shows today is still shown;
  - files stay on the device; no Spotify branding;
  - reduced motion: morphs become the 0.2 s crossfade and flourishes are instant;
  - taps, sound unlock and mute, the arrival ritual, the docked sign.
- **Palette core:** paper `#f4efe6`, ink `#111111`, signal `#e60012`, pink `#ff2d95`. Pink appears on every station.
- **Hero stat:** in **Dela Gothic One**, tabular figures, at least 63 design px wide (30% of 210). No other face for hero numbers.
- **Accent faces:** one per world beyond the core (Dela Gothic One, Zen Kaku Gothic New):

  | World | Accent face |
  |---|---|
  | C | none |
  | J | none |
  | G | Rampart One |
  | Q | Rampart One + Hachi Maru Pop |
  | B | Anton |
  | O | Bebas Neue |
  | L | Reggae One |
  | I | Shippori Mincho + Yuji Syuku |

- **Kabukicho photo** (`public/art/kabukicho.webp`):
  - CC BY-SA 4.0;
  - every slide that shows it carries a visible caption `Photo: Basile Morin, CC BY-SA 4.0`;
  - the caption is not behind a beat;
  - it is never presented as the user's photo or an artist's.
- **Images:** WebP, 1080 px wide, ≤ 200 KB each.
- **Long names:** a 40-character artist, song or genre name wraps or ellipsises inside its box. It never overflows the slide or overlaps a neighbour, verified in a real browser (`scripts/probes/long-names.js`).

## Review Focus

1. **A morph whose source is missing** (bento is passed through with no genres, so torii → sumo; and any other gap). Expected: it falls back to the ride, with no leftover overlay (tests in Tasks 13–14).

3. **The CC BY-SA credit under reduced motion and after a tap-to-finish.** Expected: always visible, since it carries no `data-beat` (test in Task 2).
4. **Long names in all nine new layouts.** Expected: the browser probe reports 0 overflows and 0 overlaps (checked in every station task).

- `loadWorldFonts(w: World): void` appends one `<link rel="stylesheet" data-world="<w>">` with those families and `&display=swap`, once per world. Worlds with no fonts add nothing.

# F5 · Heavy numbers

**Action:** watch the number count up; tap it to recount; tilt the phone sharply.

**Response:** the demo number (28,613 minutes) counts from 0, runs a little past the target and settles back, as if it had weight. A sharp tilt jolts the digits so they bounce.

**Feeling:** the number is an object with mass, not text that appears.

**Data:** none. A labelled demo number.

**Cost:** one GSAP tween per count; tilt bounce is one short tween. The first tap asks for tilt permission (iOS needs a tap). Under reduced motion the number just shows.

**Kill if:** the overshoot looks like a glitch rather than weight.

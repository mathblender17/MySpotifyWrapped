# F1 · Momentum train

**Action:** swipe or drag sideways across the station strip. A quick flick, or a slow drag.

**Response:** the strip follows the finger. On release it keeps its speed (inertia) and settles into the nearest station on a spring. A flick rattles through several stops, a slow drag scrubs and snaps back. The first and last stops stretch like elastic.

**Feeling:** the ride is a heavy thing with momentum, not a slideshow. Each stop lands with a rail clack.

**Data:** none. Demo cards use the 13 station names from the route.

**Cost:** one animation frame loop only while settling, one transform per frame. Sound and vibration only after the first tap, never under reduced motion. Android vibrates; iPhone gets the sound.

**Kill if:** it feels floaty or the clack feels like noise.
